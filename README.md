Deskripsi Projek
Program ini dibuat untuk membantu pengguna menghitung belanja dengan cara yang sederhana. Pengguna memasukkan nama barang, harga barang, jumlah yang dibeli, dan uang pembayaran. Program akan menghitung total belanja, memberikan diskon jika memenuhi syarat, serta mengecek apakah uang pembeli cukup atau tidak.

---

Fitur-Fitur Dalam Program
1. Menghitung Subtotal: Menghitung total harga barang berdasarkan harga dan jumlah barang yang dibeli.
2. Diskon Otomatis 10%: Pembeli mendapatkan diskon 10% jika total belanja lebih dari Rp100.000.
3. Validasi Input:
   - Nama barang ga boleh kosong.
   - Harga barang harus lebih dari nol.
   - Jumlah barang harus berupa angka bulat dan lebih dari nol.
4. Mengecek Pembayaran:
   - Jika uang pembeli cukup, program akan menampilkan status pembayaran lunas dan jumlah kembalian.
   - Jika uang pembeli kurang, program akan menampilkan status pembayaran kurang dan jumlah uang yang masih harus dibayar.
